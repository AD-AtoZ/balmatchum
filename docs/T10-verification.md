# T10 기기 확인

브랜치: `T10-route-to-watch`. 아래 기기 확인은 아직 수행하지 않았다.

## 정상 전송

1. 같은 패키지·서명으로 빌드한 휴대폰/워치 앱을 설치하고 두 기기를 연결한다.
2. 휴대폰의 위치 서비스를 켜고 앱에서 ‘연결된 워치 확인’을 누른다.
3. 현재 위치와 떨어진 장소를 검색해 선택하고 미래 도착 시각을 고른다.
4. ‘워치로 보내기’를 누르고 정확한 위치 권한을 허용한다.
5. 현재 위치 찾기 → 경로 받기 → 워치 전송 상태와 성공 안내를 확인한다.
6. 워치 목적지 목록 맨 위에 📱와 선택한 장소 이름이 보이는지 확인한다.
7. 목적지를 선택해 도착 시각이 전달됐는지 확인하고 안내를 시작한다. 출발지가 공대 5호관에 고정되지 않고 휴대폰 현재 위치 근처인지 확인한다.

## 실패와 재시도

- 위치 권한을 거부하거나 대략적 위치만 허용한다. 전송하지 않고 정확한 위치 권한 안내가 나오는지 확인한다. 반복 거부 후에도 ‘앱 위치 권한 설정’에서 허용하고 다시 보낼 수 있어야 한다.
- 위치 서비스를 끈다. 위치 설정 안내가 나오고 ‘휴대폰 위치 설정’에서 켠 뒤 다시 보낼 수 있어야 한다.
- 위치가 잡히지 않는 환경에서 요청한다. 제한 시간 후 실패 안내가 나오고 전송 버튼이 다시 활성화돼야 한다.
- 인터넷을 끄고 전송한다. 실패 안내 후 인터넷을 켜고 재시도할 수 있어야 한다.
- 워치 연결을 끊고 전송한다. 전송 성공으로 표시하지 않고 연결 확인 안내가 나와야 한다.
- 가까운 미래 도착 시각으로 요청해 위치/경로 대기 중 시간이 지나게 한다. 만료 안내와 함께 전송을 막아야 한다.
- 위치 권한 창을 연 상태에서 화면을 회전한다. 권한 결과와 선택 장소가 유지되고 전송을 계속할 수 있어야 한다.
- 위치 측정 중 화면을 회전하거나 종료한다. 이전 측정이 취소되고 새 화면에서 재시도할 수 있어야 한다.

## 자동 검증

`gradlew.bat :mobile:assembleDebug :wear:assembleDebug :mobile:testDebugUnitTest :core:test :mobile:lintDebug --offline`

`PhoneRouteRequestTest` 7개는 현재 위치·입구 좌표 전달, 이름/경로/도착 시각 보존, 요청 전·위치 대기 중·경로 대기 중 만료, 잘못된 경로, 위치 실패, 취소 처리를 확인한다. 실제 센서·권한 창·네트워크·워치 수신 확인은 위 기기 절차로 수행한다.
